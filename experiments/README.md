# Evidence map

Read a protocol before its result. The knee and fMoW development cohorts have already been viewed; their new runs are exploratory evidence, not independent confirmation. Results from a frozen-feature fit, a one-time snapshot step, and persistent end-to-end training answer different questions and must not be pooled.

| Question | Best record | Status and interpretation |
| --- | --- | --- |
| What is TraLO, and what differs from Kassif's method? | [Method and novelty guide](../docs/THESIS_METHOD.md), [Kassif repository audit](claude_yuval_repo_audit_20260927.md) | The current single-cap knee step tests a count-gradient direction and boundary search. It does not isolate the original penalty curve. |
| Does a TraLO step on a trained knee snapshot help? | [ResNet18/RegNetY](claude_stepens_result_20260928.md), [MobileNetV3/B5](claude_stepens_additional_result_20260928.md) | Development-only: small positive effects on some backbones, harm on B5. These are side-copy steps, not persistent training. |
| Does TraLO help throughout matched knee training? | [Fixed knee protocol](knee_persistent_kassif_match_protocol_draft_20261001.md), [ViT replay correction](knee_vit_replay_recovery_20261001.md) | B5/MobileNetV3 full queues were dispatched on 1 October 2026. No accepted complete-block score yet. ViT's original pilot failed an integrity check; a corrected, distinct release and fresh pilot are prepared. Because ViT and the other backbones use different frozen runner releases, each must pass a release-specific independent gate before their results can be combined. Do not infer quality from partial runs. |
| What did Kassif's training recipe contribute? | [Matched pipeline result](claude_yuval_pipeline_result_20260927.md), [recipe factorial](claude_recipe_factorial_result_20260927.md) | Augmentation explains much of the ordinary-classifier gain. It must be given to TraLO and controls alike. |

The [short PDF](../output/pdf/tralo_meeting_brief_20261001_v2.pdf) is for a meeting. The [long numerical PDF](../output/pdf/tralo_research_status_20261001_v2.pdf) and [paper draft](tralo_paper_results_draft_20260930.md) retain more detail; neither promotes a development result to a sealed-test claim.

For the fixed knee block, the independent scorer's `--score-mixed` mode authenticates B5/MobileNetV3 runs against their original runner release and ViT runs against its corrected release. It requires all 36 prespecified runs and completes every label-blind gate before development-label scoring. A failed or incomplete block produces no accepted score.

`configs/` contains immutable inputs whose paths are part of old run provenance. `*_protocol*` and `*_prereg*` state decisions made before scores; `*_result*` records outcomes, including failures and losses. [Archived notes](archive/provenance_20261001/README.md) remain hash-verifiable. The 1,656-image Chen test and the reserved fMoW countries are not a source for another exploratory selection.
