# Archived research notes (1 October 2026)

The first 21 documents were moved out of the top-level `experiments/` directory
after a repository-wide reference scan found no other file naming them. Three
superseded root documents were then added: the original rebuild README, the
night plan and the morning report. They are retained as historical evidence,
including failures; their original text was not edited during archival.

[`manifest.json`](manifest.json) records each original path, archived path, and
SHA-256 digest. A previous release still has the documents at their original
paths. To restore one in a future branch, move it back to the recorded original
path and verify its SHA-256 against the manifest. Relative links inside an
archived document were written for its original directory and may need that
original location to resolve.

The archive is not a source of current winner claims. Read the active results
through [`experiments/README.md`](../../README.md) and check their provenance.
