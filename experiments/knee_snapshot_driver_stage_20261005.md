# Approved snapshot pilot: training and scoring components

The approved knee experiment now has a training/artifact driver and a complete
four-run scorer around the existing six-arm snapshot core. One supervised fit
produces isolated corrections each epoch; all six arms use the same selected
snapshot window. The driver retains exclusive outputs, append-only failure
events, initial/restored checkpoints, public input copies, epoch state hashes,
source hashes and saved probability artifacts. Runtime has no private target
argument. It reuses the Yuval task loop and neutral image readers.

The label-free run verifier checks artifact bytes and paths, public identity and
label boundaries, early stopping using training-carve losses, task update counts,
restored best state, snapshot counts/residuals/doses/control matching, inactive
parity and independently recomputed averages. The scorer verifies all four
distinct complete runs with common source/input/recipe before its first private
development-target read. It authenticates and parses the same private bytes,
joins exact IDs and evaluates every arm under both common allocators. It reports
all ten declared contrasts with paired t(3) intervals and Holm adjustment, plus
accuracy, weighted/macro/grade-3 F1, group metrics and policy feasibility.

Local evidence at this stage consists of 29 new focused CPU nodes, including
active/inactive corrections, exact reference PTO trajectory and restored state,
rehashed semantic/artifact tamper refusal, failure preservation, missing/invalid
physical UUID refusal before tensor imports, complete-panel label access denial,
exact private joins and independent metric/statistical arithmetic. One new
four-run rehearsal used tiny models, fictitious RGB inputs/targets, Yuval
transforms, fake seeds 81–84 and an explicit two-epoch CPU fixture horizon. No
scientific seed, pretrained checkpoint, real target, sealed test, completed model
or GPU was used. An initial tamper test correctly encountered an earlier event
binding gate; its original source/failure is preserved. The fixture was updated
to rebind the claimed tampered event as well, exercising the deeper independent
average check. A later golden metric fixture initially assumed capped-first

preserved. A separate fixed confusion fixture now verifies metric arithmetic,
