# Knee grade-3-only development comparison

**Finding:** Matching the paper's *single constrained grade* and its six capacity fractions did not make the existing TraLO count loss reliably improve the deployed grade-3 selections. This is a 96-fit frozen-ResNet18-head development study, not a replication of the published EfficientNet method or a held-out conclusion. Full protocol: [kassif_single_cap_protocol_20260924.md](kassif_single_cap_protocol_20260924.md).

The Chen OAI archive has 4,130 knee pairs and a 5,778/826/1,656 image split. The untouched test portion contains 223 grade-3 images, matching the source manuscript's 89–201 cap scale, but it was **not scored** here. The development cohort has 826 images. Its capacity reference of 108 expected grade-3 cases comes only from 757/5,778 training prevalence, then 40–90% gives caps 43/54/65/76/86/97. The observed development label count, **106 grade-3 images**, was used only for offline metrics. Prior raw model outputs of about 34–39 are prediction counts, not cap sizes.

Four new shared seeds 1201–1204 received 20 identical supervised head epochs, five CE-only warmup epochs, batch 256 and task Adam .001. TraLO used separate constraint Adam .0003; ALM used the existing PHR variant at rho .05. Clipper, phase-matched TraLO Null, TraLO and ALM all received each identical cap. The primary metric below is **grade-3 F1 in percentage points after exact-slot `capped_first` allocation**. Higher caps naturally allow more possible true positives, so within-row method contrasts matter; increasing F1 down the table is not evidence of a better model. Upper-bound correction and raw outputs were audited separately, not pooled.

The zero intervals mean **this metric tied in these four seeds**, not that predictions or underlying models were identical or that a population effect is proven absent. At 70%, seed-level TraLO−Null differences were 0, +1.10, 0 and −1.10; at 90% they were 0, +0.99, 0 and +0.99. No positive contrast survived the prespecified six-cap Holm family. These are repeatedly inspected validation data, so even a positive adjusted result would need independent confirmation.

The loss did act on raw predictions. At 40%, Null's four raw grade-3 counts were **89, 91, 46, 91**; TraLO's were **62, 63, 31, 59**, following 15 applied constraint updates in each fit. Yet only **1, 1, 2, 1** of the 43 allocated grade-3 slots changed between Null and TraLO across the four seeds, and none of those substitutions changed the number of correct grade-3 assignments. At 50–80%, TraLO generally replaced only 0–3 allocated grade-3 slots per seed, with no net correct selection at 50%, 60% or 80%; gains and losses cancelled at 70%. At 90%, two seeds each gained one correct slot. This points to a specific limitation of the present loss: it often changes **how many** cases are raw grade-3 predictions without meaningfully improving **which cases rank above the deployment cutoff**. It is not a proof that all constraint-aware learning must fail; this experiment trains only the linear head on frozen features.

The release passed 94 local tests and both-host native regression/CLI/source-byte checks plus GPU smoke on free dsisco01 GPU0. Full-run artifact hashes, 460 applied supervised updates per fit, actual constraint dose, paired warmup/batch hashes, saved raw predictions, exact slots and independently recomputed metrics passed audit. TraLO constraint dose decreased from 15 to 11–13 updates in some 90% fits because the wider cap was already satisfied at other opportunities. ALM applied 345 joint constraint-bearing task updates and 15 dual updates per fit; equal epochs therefore do not imply equal compute.

**Next research step:** test whether constraint gradients can improve the representation, rather than only a frozen-feature classifier head. Predeclare one-cap matched end-to-end backbone training with Clipper, phase-matched Null and TraLO, first with one-seed integrity/dose checks and then four paired seeds. Keep the held-out test untouched during development, retain both allocation policies, and measure cutoff membership changes. Separately, define a training-label-only objective that rewards correct candidate ordering near the grade-3 quota cutoff; compare it with a matched null rather than tuning the existing count step indefinitely. The submitted manuscript names EfficientNet but omits the exact variant and full hyperparameters available to us, so an exact Yuval replication still awaits author code or final methods.
