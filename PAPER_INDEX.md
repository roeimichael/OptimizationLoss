## TL;DR — everything the paper needs is now inside `final_AAAI_PAPER/`

| You want… | It's here |
|---|---|
| **The paper itself** (submit / edit / read) | **`final_AAAI_PAPER/main.tex`** |

The paper is **self-contained**: every figure script and table draws only from
`final_AAAI_PAPER/data/`. It no longer reaches into the raw run tree, so it cannot
accidentally pull a non-paper dataset or backbone. There is exactly **one** `main.tex`.

## The submission — `final_AAAI_PAPER/`
The self-contained, Overleaf-ready AAAI package (~6 body pages + refs + appendices, 9pp total).
- `main.tex` — the manuscript. Headline = a learning-QUALITY metric (cc-F1 / macro-F1);
  native satisfaction + flips are demoted to Appendix C. Built on the OFFICIAL `aaai2026.sty`
  (anonymous `[submission]`, natbib author–year). Compile with `build_pdf.sh` (MiKTeX).
- `data/` — **all paper data** (corpus CSVs + the per-epoch dynamics logs); see `data/README_DATA.md`.
- `figures/` — the 5 figures `main.tex` includes (loss_shape, octmnist, convergence in the body;
  mechanism, deployment in the appendices), each as `.pdf` (vector, used by pdflatex) + `.png`
  (used by the HTML preview); included extensionless. Regenerated by `scripts/make_*.py` via
  shared `scripts/fig_style.py`.
- `tables/` — the 4 `\input` floats: `tab_ccf1.tex` (body), `tab_regime.tex` (body),
  `tab_deploy.tex` (Appendix C), `tab_ablation_complete.tex` (Appendix B). **Hand-maintained**
  from `data/corpus/corpus_final.csv` — their old generators were superseded by manual edits.
- `scripts/` — `make_*.py` that regenerate the figures from `data/` (+ `fig_style.py`).
- `paper.html` — readable preview (built by `../scripts/build_paper_html.py`).
- `references.bib` — the 22-entry bibliography (all cites resolve).
- `STRONG_RESULTS_CHECKPOINT.md`, `EVIDENCE_PLAN.md` — the frozen audited claims + evidence map.

## `final_AAAI_PAPER/data/` — the single data home
- `corpus/corpus_final.csv` — **MASTER corpus**. `sweep=='paper_final'` = the locked headline
  grid (3 backbones {MobileNetV3, ViTB16, RegNetY400MF} × {tissue, derm, oct} × 9 caps × 6
  methods × 4 seeds). Feeds octmnist + deployment figs and (by hand) all 4 tables.
- `corpus/extra_robustness_corpus.csv` + `ablation_complete.csv` — the ablation campaign
  (future work); `CAMPAIGN_RESULTS.md` = its verdicts.
- `dynamics/` — the 26 per-epoch `training_log.csv` behind `fig_convergence` (tissue/derm L30)
  and `fig_mechanism` (derm asym L50_G20). Provenance in `data/README_DATA.md`.

## How to rebuild (pipeline)
1. **Figures**: `python final_AAAI_PAPER/scripts/make_{figs,convergence_fig,octmnist_fig,deployment_fig}.py`
   → write `.pdf`+`.png` into `final_AAAI_PAPER/figures/`. All read only `final_AAAI_PAPER/data/`.
2. **Tables**: hand-maintained `.tex` in `final_AAAI_PAPER/tables/` (source of truth =
   `data/corpus/corpus_final.csv`; re-running the old generators would revert manual edits).
3. **Compile**: `final_AAAI_PAPER/build_pdf.sh` (MiKTeX) — `pdflatex; bibtex; pdflatex ×2`.
4. **Render HTML**: `python scripts/build_paper_html.py` → `final_AAAI_PAPER/paper.html`.
