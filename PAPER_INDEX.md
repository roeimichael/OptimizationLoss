## TL;DR — everything the paper needs is now inside `final_AAAI_PAPER/`

| You want… | It's here |

accidentally pull a non-paper dataset or backbone. There is exactly **one** `main.tex`.

## The submission — `final_AAAI_PAPER/`
The self-contained, Overleaf-ready AAAI package (~7 body pages + refs + separate supplement).
- `main.tex` / `supplementary.tex` — the manuscript + separate supplement. Headline = a
  learning-QUALITY metric (cc-F1 / macro-F1); native satisfaction + flips are demoted to the
  appendices. Built on the OFFICIAL `aaai2027.sty` (anonymous `[submission]`, natbib
  author–year). Compile with `build_pdf.sh` (MiKTeX): `pdflatex; bibtex; pdflatex ×2`.
- `data/` — **all paper data** (corpus CSVs + the per-epoch dynamics logs); see `data/README_DATA.md`.
- `figures/` — the figures the manuscript includes (loss_shape, octmnist, convergence,
  mechanism, deployment, datasets), each as `.pdf` (vector, used by pdflatex) + `.png`
  (used by the HTML preview); included extensionless. Regenerated by `scripts/make_*.py` via
  shared `scripts/fig_style.py`.
- `tables/` — the `\input` floats. `tab_ccf1.tex` is the headline (body); the rest are appendix
  tables. Generated by `scripts/make_*table*.py` from `data/corpus/corpus_final.csv`.
- `scripts/` — `make_*.py` that regenerate the figures/tables from `data/` (+ `fig_style.py`),
  and `build_paper_html.py` (HTML preview).
- `paper.html` — readable preview (built by `scripts/build_paper_html.py`).
- `references.bib` — the bibliography (all cites resolve).
- `STRONG_RESULTS_CHECKPOINT.md`, `EVIDENCE_PLAN.md` — the frozen audited claims + evidence map.

## `final_AAAI_PAPER/data/` — the single data home
- `corpus/corpus_final.csv` — **MASTER corpus**. `sweep=='paper_final'` = the locked headline
  grid (3 backbones {MobileNetV3, ViTB16, RegNetY400MF} × {tissue, derm, oct} × 9 caps × 6
  methods × 4 seeds). Feeds octmnist + deployment figs and the tables.
- `corpus/review_*_2026-07.csv` — the review-round control/graft/convergence corpora
  (fairness sweep, graft campaign); `review_graft_2026-07.csv` feeds the graft table.
- `dynamics/` — the per-epoch `training_log.csv` behind `fig_convergence` (tissue/derm L30)
  and `fig_mechanism` (derm asym L50_G20). Provenance in `data/README_DATA.md`.

## The archive — `archive/` (gitignored, one consolidated tree)
Everything NOT in the paper lives under a single `archive/` (consolidated 2026-07-17; nothing
deleted, recoverable on disk):
- `raw_runs/` — the full 2.3 GB raw run tree (`pending_runs/` + `server_only_sweeps/`): all
  datasets (incl. dropped **eurosat**), all backbones (incl. non-paper MobileNetV2 /
  ShuffleNetV2 / ResNet18 / EfficientNetB0), ~40 exploratory sweeps, and the raw **ablation**
  sweeps (`g5_component_ablation`, `g5_short_warmup`, `kl_ablation`, `tablef_shortwarm`). **All
  already aggregated into `corpus_final.csv`**, so no metric is lost; kept as the
  raw-data-of-record should the ablation be extended. Also holds `paper_aaai_tables_scratch/`
  (the former `paper/aaai_tables/` corpus + stale intermediates).
- `legacy/` — superseded drafts + tooling: `eaai_paper_draft/` (the Elsevier/EAAI journal
  draft, AIDER not OctMNIST), `paper_planning_2026-07/` (superseded planning docs +
  `tab_regime.tex`, no longer used), `scratch_fairness/`, and the old paper `scripts/`/`tables/`.
- `scratch/` — the ~130 one-off analysis scripts archived 2026-07-17: `root_scripts/` (the
  former root `scripts/`), `config_gen_archive/` (former `src/config_generators/_archive/`),
  and `paper_scratch/`. Superseded; not needed to build the paper.

## How to rebuild (pipeline)
1. **Figures**: `python final_AAAI_PAPER/scripts/make_{figs,convergence_fig,octmnist_fig,deployment_fig,datasets_fig,loss_shape_fig}.py`
   → write `.pdf`+`.png` into `final_AAAI_PAPER/figures/`. All read only `final_AAAI_PAPER/data/`.
2. **Tables**: `python final_AAAI_PAPER/scripts/make_{main,backbone,granular,graft}_table*.py`
   (source of truth = `data/corpus/corpus_final.csv`), writing `tables/*.tex`.
3. **Compile**: `final_AAAI_PAPER/build_pdf.sh` (MiKTeX) — `pdflatex; bibtex; pdflatex ×2`.
4. **Render HTML**: `python final_AAAI_PAPER/scripts/build_paper_html.py` → `final_AAAI_PAPER/paper.html`.
